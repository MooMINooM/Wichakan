# GPA รายภาคเรียน และ GPAX สะสมจากภาคเรียนที่สมบูรณ์

## หลักเกณฑ์การคำนวณ
- สำหรับมัธยมศึกษาตอนต้น (ม.1–ม.3) ระบบแสดง **GPA แต่ละภาคเรียน** รวมสูงสุดหกภาคเรียน และ **GPAX สะสม** หลังแต่ละภาคที่สมบูรณ์
- คำนวณจากเกรดที่ตัดสินแล้วทุกวิชา รวมเกรด 0 ของ SchoolMIS กับหน่วยกิตที่ตรวจสอบแล้ว ตามสูตร `sum(grade × credits) / sum(credits)`
- ไม่ใช้ GPA ที่ปัดเศษแต่ละเทอมมาเฉลี่ยใหม่; ใช้ผลรวมตัวตั้ง/ตัวหารเต็มความแม่นยำและปัดผลตอนแสดงสองตำแหน่ง
- การคำนวณ GPA รายภาคต้องมีจำนวนรายวิชาตรงกับหลักสูตรที่ใช้ในปีการศึกษาปัจจุบัน (เช่น ม.1–ม.3 มี 18 รายวิชาผลทางการต่อภาค) และทุกรายวิชามีผลตัดสิน/หน่วยกิตสมบูรณ์
- **GPAX สะสม** ใช้ภาคเรียนที่สำเร็จครบต่อเนื่องตั้งแต่ต้นช่วงชั้นเท่านั้น ไม่รวมภาคปีปัจจุบันที่เริ่มลงคะแนนแต่ยังไม่ครบ
- เมื่อภาคเรียนถัดไปครบ ระบบคำนวณสะสมเพิ่มขึ้นอัตโนมัติ ไม่ต้องเพิ่มผลย้อนหลังซ้ำ
- ไม่รวมวิชาคอมพิวเตอร์แยก `ง21201/ง21202`, `ง22201/ง22202`, `ง23201/ง23202` ตามข้อตกลงเรื่อง ปพ.6/GPAX; กิจกรรมพัฒนาผู้เรียนไม่อยู่ใน GPA

## พื้นที่ใช้งาน
- `/students/transcript`: ประวัติรายคน พร้อมตาราง GPA ภาคเรียน 1–6, GPAX สะสมหลังแต่ละภาค, และ CSV รายคน
- `/students/schoolmis/gpa`: สรุปรายห้อง โดยเลือกระดับชั้น/ปีการศึกษา แสดง GPA แต่ละเทอมพร้อม GPAX สะสมล่าสุดของนักเรียนทุกคน และ CSV รายห้อง
- RPC `schoolmis_student_semester_summary(school_id,student_id)` และ `schoolmis_class_semester_summary(school_id,year_be,classroom_id)`: จำกัดสิทธิ์เฉพาะ Admin/งานทะเบียน ด้วยการตรวจ school_memberships

## การทดสอบกับข้อมูลจริง ม.3/1 ปี 2569
- นักเรียน 16 คนมี GPA ครบสี่ภาคเรียน (ม.1 ปี 2567 และ ม.2 ปี 2568) และ GPAX สะสม **4 ภาคเรียน** ครบทุกคน
- เกรด 0 ทั้ง 22 รายการอยู่ในตัวคำนวณจริง รวมถึงกรณี GPA ภาคเรียนเท่ากับ 0.00
- GPA/GPAX ของนักเรียน 16 คนเปรียบเทียบกับ SQL `sum(grade_value × weight_units)/sum(weight_units)` ตรงกัน 16/16 คน ความคลาดเคลื่อน 0 คน
- ปริมาณหน่วยกิต ม.1–ม.2 รวม 56 หน่วยกิตต่อคน จาก 72 รายวิชาตลอด 4 ภาคเรียน
- ผล ม.3 ปี 2569 ยังลงไม่ครบ จึงไม่ถูกนำเข้าไปใน GPAX 4 ภาคเรียน
- ไม่เพิ่มหรือแก้คะแนนครูที่เก็บอยู่ใน `student_course_scores`

## ข้อควรระวัง
หากเปลี่ยนโครงสร้างหลักสูตร หรือจำนวนรายวิชาภาคใด ให้ตรวจสอบการนับรายวิชาที่ใช้รับรอง GPA ใน migration ของฟังก์ชันสะสม เพื่อไม่รับรองผลที่ยังไม่ครบโดยไม่ตั้งใจ
