# WICHAKAN — นำเข้า SchoolMIS อย่างปลอดภัยและเตรียมการกู้คืน

## สถานะ ณ 30 ตุลาคม 2569
- ระบบประวัติย้อนหลังนำเข้าผ่านการตรวจสอบสิทธิ์ และเก็บข้อมูลแยกจากคะแนนครู
- ระบบ GPAX สะสมจะไม่รับรองค่าจนกว่าจะครบทุกปี/ภาคเรียนที่คาดหมาย ทุกผลรายวิชา และน้ำหนัก
- **ยังไม่ได้มีหลักฐานยืนยันว่ามีไฟล์สำรองที่กู้คืนได้** จาก Supabase Dashboard: เครื่องมือที่เชื่อมกับ WICHAKAN ในงานนี้ไม่แสดงการตั้งค่าและรายการ backup จริงของโครงการ
- **ไม่ได้ดำเนินการกู้คืนหรือทดสอบกู้คืนบน production** และไม่ได้โหลดไฟล์ CSV ของนักเรียนจริงเข้าสู่ฐานข้อมูล

## การเตรียมก่อนนำเข้าข้อมูลจริง
1. ผู้ดูแลระบบตรวจสอบ **Database → Backups** ของโครงการ Wichakan ใน Supabase Dashboard ว่ามี recovery point ที่เพิ่งสร้างและสถานะพร้อมใช้งาน หากแผนไม่มี backup ให้สร้างและเก็บไฟล์ backup แบบ logical ของโครงการด้วย Supabase CLI/pg_dump ตามคู่มือที่รองรับ
2. สำรองไฟล์ใน **Supabase Storage** แยกจากฐานข้อมูล: backup ฐานข้อมูลเก็บข้อมูลอ้างอิงไฟล์ แต่ไม่เก็บ object bytes; ตรวจว่ามีแฟ้มเก็บสำเนาและสิทธิ์เข้าถึงที่เหมาะสม
3. เก็บสำเนาในที่จัดเก็บซึ่งไม่ใช่โครงการ Supabase เดียวกัน ป้องกันการสูญเสียพร้อมกัน จำกัดสิทธิ์ และเข้ารหัสตามนโยบายโรงเรียน
4. ทดสอบกู้คืนใน **โครงการทดสอบแยกต่างหาก** และตรวจตารางนักเรียน เอกสาร และรายการคะแนนตัวอย่างก่อนรับรองว่ากู้คืนได้จริง ห้ามทดลอง restore ทับ production
5. เมื่อตรวจสอบครบแล้วจึงเลือกไฟล์ SchoolMIS ต้นฉบับ ตรวจรหัสนักเรียนกับชื่อ–นามสกุล และเลือกยืนยันในหน้าระบบ

คู่มือผู้ให้บริการ: https://supabase.com/docs/guides/platform/backups

## หน้าจอ WICHAKAN ที่พัฒนาแล้ว
- `/students/schoolmis` — นำเข้าและตรวจความแตกต่างของ CSV (ต้องรับรองว่ามีสำเนาสำรองก่อนกดบันทึก)
- `/students/schoolmis/weights` — ตรวจหน่วยน้ำหนักตามรายวิชา/ปี/ชั้น/ภาค และบันทึกหลักฐานอ้างอิง
- `/students/schoolmis/weights/bulk` — ดาวน์โหลดแม่แบบ CSV ของรายวิชาที่ย้อนหลัง พร้อมนำเข้าหน่วยน้ำหนักหลายวิชาแบบ atomic
- `/students/transcript` — ประวัติรายคน เชื่อมข้อมูลย้อนหลัง + ปีปัจจุบัน พร้อมสถานะครอบคลุมแต่ละช่วงปี และแสดง GPAX เฉพาะที่ครบถ้วน

## ข้อมูลที่ห้ามปนเปื้อน
- ไฟล์ CSV ของผู้เรียนและรายงานรายบุคคลไม่ควรนำเข้า repo GitHub หรือส่งในช่องแชทสาธารณะ
- ปพ.5 ปพ.6 เกรดทางการ และคะแนนที่ครูบันทึกอยู่ไม่ควรถูกแก้ย้อนหลังโดย importer
- เมื่อไฟล์หนึ่งมีผลขัดแย้งกับข้อมูลเดิม ต้องยกเลิกการนำเข้าทั้งธุรกรรม
- การยืนยันหน่วยน้ำหนักย้อนหลังต้องเก็บผู้ยืนยัน เวลา และรายละเอียดแหล่งอ้างอิง
