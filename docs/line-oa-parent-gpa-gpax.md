# GPA / GPAX ใน LINE Official Account — WICHAKAN

## สิ่งที่ผู้ปกครองเห็น
ใน **LINE OA → บริการข้อมูลบุตรหลาน → ตรวจสอบผลการเรียน** หลังเข้าสู่ระบบ LIFF และเลือกบุตรหลาน/ปีการศึกษา/ภาคเรียน:
- ตารางคะแนนและผลการเรียนตามสิทธิ์เดิม
- **GPA** ของปี/ภาคเรียนที่เลือก: ประถมแสดง GPA **รายปีหลังจบภาค 2 เท่านั้น**; มัธยมแสดง GPA **รายภาคเรียน**
- **GPAX สะสม** ล่าสุดที่มีผลการเรียนครบต่อเนื่อง ถึงปี/ภาคเรียนที่เลือก และข้อความ **สะสมถึง** ปี/ชั้น/ภาคที่ใช้คำนวณจริง
- หากรายวิชาของปี/ภาคเรียนที่เลือกยังไม่ครบ จะแสดง GPA = — และ GPAX สะสมจากช่วงก่อนหน้าที่ครบแล้ว (หากมี); ไม่เฉลี่ยคะแนนบางวิชา
- ถ้ายังไม่เคยมีปี/ภาคเรียนที่พร้อมคำนวณ จะแสดง — แทนตัวเลขปลอม

## กติกาสิทธิ์
1. Edge Function `line-parent` ตรวจ LINE ID Token กับ LINE และยืนยัน channel ก่อนเชื่อมฐานข้อมูลด้วย service role
2. ฟังก์ชัน `line_parent_portal_data` ตรวจจับคู่บัญชี LINE → ผู้ปกครอง → นักเรียน และ **ประกาศผล Admin (line_grade_publications.published_at)** สำหรับปีและภาคที่เลือก
3. **เฉพาะ** หลังตรวจทั้งข้อ 1–2 แล้วจึงเรียกตัวคำนวณเดียวกับหน้าแฟ้มประวัติ WICHAKAN `schoolmis_student_semester_summary`, ใช้เกรด/หน่วยกิตจริงและช่วงที่ผลครบต่อเนื่อง ไม่รวมวิชาที่ไม่ใช่ผลทางการ
4. GPAX ที่ส่งให้ผู้ปกครองจำกัดถึงช่วงที่เลือก ไม่แสดงค่าเฉลี่ยของช่วงถัดไปที่ยังไม่ประกาศ
5. กรณียังไม่ประกาศภาคเรียน, นักเรียนไม่มีความสัมพันธ์ผู้ปกครองที่ยืนยัน หรือผู้ใช้ไม่ใช่ service role: **ไม่ส่ง GPA / GPAX**
6. เมื่อเปลี่ยนบุตรหลาน/ปี/ภาค UI ต้องล้างค่า GPA/GPAX เก่าเพื่อไม่ให้แสดงข้อมูลของคนก่อนหน้า
7. ไม่ส่ง GPAX เป็น push message ไปหา LINE โดยอัตโนมัติ; ฟีเจอร์นี้คือการ **แสดงผลในหน้า LIFF** หลังผู้ปกครองกดตรวจสอบ

## การตรวจสอบกับฐานข้อมูลจริง
- ทดสอบกับ 2 บัญชีผู้ปกครองที่เชื่อมข้อมูลกับนักเรียน และมีประกาศผล 2569 ภาค 1: คืน GPA summary เฉพาะรายการที่อนุมัติแล้ว
- ทดสอบประกาศผลภาค 2 ที่ยังไม่เปิด: ต้องได้ `published:false`, ไม่มี `gpa_summary`
- ทดสอบผู้ปกครองข้ามบุตรหลาน: ไม่คืน `gpa_summary`
- ทดสอบหน้าประถมภาค 1: **GPA รายปีเป็น null** ไม่เอาคะแนนระหว่างปีไปตัดเกรด
- จำกัด RPC `line_parent_portal_data` ให้ service role เท่านั้น (anon/authenticated ไม่มี execute)
- ไม่มีการเปลี่ยนผลการเรียน, หน่วยกิต, คะแนนครู, สถานะการประกาศ หรือข้อมูลเชื่อมบัญชีของผู้ปกครอง
