# กฎรายวิชาทางการของ WICHAKAN เทียบกับ SchoolMIS (ปีการศึกษา 2569)

ข้อกำหนดนี้อ้างอิงหัวตารางใน CSV จริงของโรงเรียน ป.1/1 ป.6/1 ม.1/1 และ ม.3/1 และยืนยันโดยผู้รับผิดชอบระบบ

## ประถมศึกษา ป.1–ป.6
- สุขศึกษา `พ1x101` และพลศึกษา `พ1x102` ยังคงเป็นรายวิชาสำหรับ **ครูบันทึกคะแนนและออก ปพ.5 แยกกัน**
- ศิลปะ `ศ1x101` และดนตรี–นาฏศิลป์ `ศ1x102` เช่นเดียวกัน
- ปพ.6 และ GPA รายปีรายงาน **หนึ่งวิชารหัส 101** จากคะแนนเต็ม 100 ของแต่ละส่วน `(scoreA + scoreB) / 2` แล้วจึงใช้เกณฑ์ตัดสินเกรด ห้ามเฉลี่ยเกรดที่ปัดขั้นแล้ว
- หน่วยน้ำหนักสำหรับรายวิชาที่รวม = ชั่วโมงเรียนของสองส่วนรวมกัน (ปัจจุบัน 40+40 = 80 ชม.) นับเป็นพื้นฐานหนึ่งรายการ ไม่คิดชั่วโมงสองครั้ง
- ถ้าส่วนใดขาดคะแนน / มี ร / มส / ข้อมูลซ้ำ ต้อง **ไม่ออกเกรดรวมที่ดูสมบูรณ์**; แสดงคำเตือนและไม่คำนวณ GPA
- การแสดงผลภาคเรียนที่ 1 ของประถมยังระบุว่า **ระหว่างปี** ไม่ออกเกรดรายปี
- วิชาคอมพิวเตอร์ ป.4, ป.5, ป.6 เปลี่ยน **รหัส** จาก `ง14201 / ง15201 / ง16201` เป็น `ว14201 / ว15201 / ว16201` เพื่อให้ตรงกับ SchoolMIS โดยแก้รายการเดิม ไม่สร้าง UUID ใหม่และไม่ลบคะแนนเดิม

## มัธยมศึกษาตอนต้น ม.1–ม.3
- `ง21201, ง21202, ง22201, ง22202, ง23201, ง23202` คอมพิวเตอร์: คงในระบบสอน ตารางสอน คะแนน และ ปพ.5
- คอมพิวเตอร์ที่ไม่อยู่ในไฟล์ SchoolMIS เหล่านี้ **ไม่นำไปปรากฏใน ปพ.6, GPA และผลทางการใน LINE OA** ระหว่างรอตรวจสอบว่าเป็นรายวิชาที่โรงเรียนต้องรับรองหรือไม่
- `ว21103/ว21104` เป็นต้น (วิทยาการคำนวณ) เป็นอีกวิชาหนึ่ง ยังคงแสดงปกติ ไม่ผสมคะแนนกับคอมพิวเตอร์
- รายวิชาอื่นของมัธยมไม่เปลี่ยนวิธีคำนวณ

## ขอบเขตของการใช้งาน
- กลไกนี้ทำงานเฉพาะ **ผลทางการรายปี/รายภาคปัจจุบัน**: หน้าสรุป ปพ.6, หน้าเอกสารพิมพ์, GPA ใน ปพ.6 และผลที่ประกาศผ่าน LINE OA
- ปพ.5 และบันทึกคะแนนครูยังแยกวิชา
- GPAX ตลอดช่วงชั้นจากประวัติ SchoolMIS ยังต้องรอยืนยันหน่วยกิตของปีที่ผ่านมา และยังไม่ได้รวมเข้ากับ GPA ของปีปัจจุบันโดยอัตโนมัติ
- การแสดงคะแนนเฉลี่ยใน LINE OA รักษาทศนิยม .5 เมื่อเกิดขึ้น ส่วนเกรดตัดสินจากคะแนนเฉลี่ย **ก่อนปัด**
- หากเปลี่ยนหลักสูตรหรือ SchoolMIS เพิ่มรหัสวิชาใหม่ ต้องทบทวนตารางเทียบและทดสอบ ไม่ใช้กฎนี้ข้ามปีโดยไม่ตรวจสอบ
