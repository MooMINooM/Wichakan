# นำเข้าประวัติผลการเรียน SchoolMIS (ระยะที่ 1)

## ขอบเขต
เมนู **ทะเบียนนักเรียน → นำเข้าผลย้อนหลัง SchoolMIS** ใช้เฉพาะบัญชี `school_admin` และ `registrar` ของโรงเรียน ป้องกันการแก้ไขคะแนนที่ครูบันทึกอยู่ใน `student_course_scores`.

- รองรับ CSV แบบทั้งช่วงชั้น (ประถม ป.1–ป.6 และมัธยม ม.1–ม.3 รวม 6 ภาคเรียน)
- ต้องระบุ **ชั้นในชื่อไฟล์และปีการศึกษาอ้างอิง** (เช่น ป.6 ปี 2569) ระยะปีที่เก็บย้อนหลังอนุมานจากชั้นของรายวิชา
- **ไม่รับผลปีปัจจุบัน** ผ่านเครื่องมือนี้ เพื่อลดความเสี่ยงเขียนข้อมูลซ้ำกับระบบบันทึกคะแนน
- แถวของนักเรียนต้องตรง **เลขประจำตัวนักเรียนและชื่อ–สกุล** ในทะเบียน WICHAKAN; หากไม่ตรง ระบบแจ้งเตือนให้ตรวจสอบ
- **ไม่ถือว่า 0 หมายถึงเกรดจริงโดยอัตโนมัติ** ผู้ดูแลต้องยืนยันก่อนนำเข้าค่า 0
- เก็บผลกิจกรรม `ผ/มผ` แยกจากวิชาเกรดและรักษาลำดับคอลัมน์ไว้แม้รหัสกิจกรรมซ้ำ
- รายการเกรดรายวิชา (และกิจกรรม) ที่เคยนำเข้าจะแสดงเหมือนเดิมเมื่ออัปโหลดซ้ำ แต่ถ้าขัดแย้งกัน **ระบบไม่เขียนทับและยกเลิกธุรกรรมทั้งหมด**
- เก็บชื่อไฟล์ วันเวลา ผู้นำเข้า จำนวนรายการ และที่มาของแต่ละผลการเรียน; ไม่เก็บไฟล์ CSV ต้นฉบับในฐานข้อมูล

## GPAX สะสม
ข้อมูลย้อนหลังกำหนด `weight_units = NULL` และ `weight_confirmed = false` ก่อนเสมอ
ผู้ดูแลต้องตรวจสอบน้ำหนัก/หน่วยกิตจาก **หลักสูตรฉบับที่ใช้ในปีนั้น** แล้วจึงยืนยันในหน้ารายวิชา
หน้าสรุปจะไม่แสดง GPAX หากยังขาดหน่วยน้ำหนักหรือมีผล `ร/มส` ที่ยังไม่ตัดสิน

**ระยะที่ 1 นี้คำนวณเฉพาะ GPAX จากข้อมูลย้อนหลังที่นำเข้าแล้ว** ยังไม่รวมปีปัจจุบันจาก WICHAKAN และยังไม่ได้เชื่อมไปยัง LINE OA เพื่อหลีกเลี่ยงการนำค่าที่ไม่ครบไปแสดงให้ผู้ปกครอง

## วิธีตรวจสอบก่อนใช้งานจริง
1. สำรองฐานข้อมูลและตรวจสอบกระบวนการกู้คืนให้พร้อม
2. เข้าสู่ระบบด้วยบัญชี Admin/ทะเบียน → เลือกปีที่ส่งออกจาก SchoolMIS → เลือก CSV
3. ตรวจจำนวนรายวิชา กิจกรรม นักเรียน และรายการที่ระบบข้าม
4. ตรวจการจับคู่ทะเบียน: ถ้ามีชื่อหรือรหัสไม่ตรง ให้แก้ข้อมูลในทะเบียนก่อน หรืออนุมัติการข้ามเฉพาะรายการอย่างชัดแจ้ง
5. ตรวจสอบ 0 และหน่วยน้ำหนักโดยเทียบกับ SchoolMIS และหลักสูตรจริง
6. กดยืนยันบันทึก แล้วตรวจประวัติของนักเรียนตัวอย่างสอง–สามคน จากนั้นจึงดำเนินการนำเข้าห้องอื่น

**ไม่ใช้ไฟล์ตัวอย่างที่มีข้อมูลจริงเป็น fixture ใน GitHub** และไม่ส่งตัวอย่างนี้ให้บุคคลภายนอก
