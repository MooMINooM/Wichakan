# SchoolMIS: เกรด 0 เป็นผลการเรียนจริงตามไฟล์ต้นฉบับ

วันที่ยืนยัน: 30 ตุลาคม 2569

## นโยบายข้อมูล
โรงเรียนยืนยันว่าให้ยึดผลการเรียนย้อนหลังจาก **SchoolMIS** เป็นหลัก รวมถึงตัวเลข **0** ที่ปรากฏในช่องรายวิชา ให้เก็บเป็นเกรด 0 ที่ตัดสินแล้ว โดยไม่เปลี่ยนเป็นช่องว่างหรือรายวิชาไม่สมบูรณ์โดยอัตโนมัติ

ข้อมูลที่ไม่มีผล (ช่องว่าง) และสถานะพิเศษ `ร`, `มส` ยังต้องคงสถานะตามไฟล์ต้นฉบับ ไม่ถือเป็นเกรด 0 เอง

## รายการที่ปรับแก้ในการนำเข้า ม.3/1
- ปี 2567 ม.1 ภาค 1 — 3 เกรด 0
- ปี 2567 ม.1 ภาค 2 — 1 เกรด 0
- ปี 2568 ม.2 ภาค 1 — ไม่มี
- ปี 2568 ม.2 ภาค 2 — 18 เกรด 0
- รวม 22 ระเบียน จากนักเรียน 5 คน

แก้เฉพาะข้อมูลใน `schoolmis_grade_history`:
- `result_text`: `''` → `'0'`
- `grade_value`: `NULL` → `0`
- คง `source_raw_value='0'`, `source_import_id`, รหัสรายวิชา หน่วยกิต และรายชื่อผู้เรียนเดิม
- บันทึกหลักฐานเดิมและใหม่ 22 ระเบียนใน `schoolmis_grade_decision_audit` (ตารางอ่านได้เฉพาะ Admin/งานทะเบียนของโรงเรียน)

ปรับ `schoolmis_import_history` ให้รับค่า `0` ตาม SchoolMIS และแปลง payload ของหน้าระบบรุ่นก่อนที่ส่ง `source_raw_value='0', result_text=''` เป็นเกรด 0 เมื่อมีแหล่งข้อมูลต้นฉบับระบุไว้ชัดเจน

ปรับ CSV preview ให้รวมเกรด 0 อัตโนมัติโดยไม่ต้องติ๊กยืนยันทีละไฟล์

## การตรวจสอบหลังแก้ไข
- ประวัติผลการเรียนย้อนหลัง ม.1–ม.2 มีคะแนนและหน่วยกิตพร้อมคำนวณ 1,152 รายวิชารายคน
- ประวัติ SchoolMIS ทั้งหมด 1,408 ระเบียน
- คะแนนรายวิชาปัจจุบัน `student_course_scores` ยังมี 216 ระเบียน ไม่ถูกแก้
- ตรวจการนำเข้าซ้ำของไฟล์รุ่นเก่าด้วย transaction ที่ย้อนกลับทุกข้อมูลทดสอบ

**ข้อจำกัด:** การยืนยันเกรด 0 ในประวัติไม่ได้หมายความว่า GPAX ตลอดช่วงชั้น ม.1–ม.3 พร้อมรับรอง เพราะยังขึ้นอยู่กับผลการเรียนปี 2569 ว่าบันทึกครบตามหลักสูตรหรือไม่
