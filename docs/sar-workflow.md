## การอนุมัติและข้อมูลจริง

- ต้องตั้งค่าเป้าหมายหลัก 27 และเป้าหมายย่อย 57 รายการก่อน Admin ประกาศค่าเป้าหมายของปีนั้น
- ครูทุกคนประเมินมาตรฐานที่ 2–3 ตามแบบต้นฉบับ แต่ **คะแนน 1–5 ยังไม่ถูกแปลงเป็นร้อยละโดยอัตโนมัติ** เพราะแบบประเมินต้นฉบับยังไม่กำหนดสูตรรวมคะแนน
- ผลการประเมินมาตรฐานที่ 1 โดยครูประจำชั้นต้องครบจำนวนนักเรียนจึงจะสามารถนำผลรวมเข้า SAR ได้
- เกรดระดับ 3 ขึ้นไปใช้เฉพาะเกรดที่ผ่านการตรวจสอบข้อมูลครบตามกฎระบบ โดยไม่ใช้ 0 แทนคะแนนที่ขาด
- Admin ตรวจผลรายประเด็นและลงนามรับรองด้วยสิทธิ์ระบบก่อนสร้างรายงานฉบับรับรอง
- รายงานฉบับอนุมัติเป็น snapshot แยกรุ่น ไม่ถูกเปลี่ยนตามการแก้ข้อมูลปัจจุบัน

## เชื่อม Google Drive ของโรงเรียน (ต้องตั้งค่า OAuth โดยผู้ดูแลบัญชี Google)

1. ใน Google Cloud Console ให้เปิด Google Drive API และตั้งค่า OAuth consent screen เลือกประเภทผู้ใช้ที่เหมาะสม
2. สร้าง OAuth Client ID แบบ **Web Application**, กำหนด Authorized Redirect URI ให้ตรงกับ:
   `https://itmgezrxnqttngsmgxlo.supabase.co/functions/v1/sar-drive?action=callback`
3. ใน Supabase ของโปรเจ็กต์ ให้ตั้ง Edge Function Secrets ดังนี้:
   - `SAR_GOOGLE_CLIENT_ID`: OAuth client ID
   - `SAR_GOOGLE_CLIENT_SECRET`: OAuth client secret
   - `SAR_DRIVE_STATE_SECRET`: สตริงสุ่มความยาวสูงสำหรับเซ็น OAuth state
   - `SAR_DRIVE_ALLOWED_ORIGINS`: `https://moominoom.github.io` (เพิ่ม localhost เฉพาะกรณีพัฒนา)
4. ไปที่ `/admin/sar/management/` แล้วกด **เชื่อม Google Drive** ลงชื่อเข้าใช้บัญชี Google ที่โรงเรียนอนุญาตให้ใช้จัดเก็บหลักฐาน
5. ครูอัปโหลดไฟล์ลง Wichakan (Storage ส่วนตัว) ได้ก่อน เมื่อต่อ Google Drive สำเร็จ ระบบจะสำรองไฟล์ใหม่เข้า Drive โดยอัตโนมัติ และมีปุ่มส่งไฟล์เดิมอีกครั้ง

โครงสร้าง Drive:
`Wichakan SAR/บุคลากร/<ชื่อบุคลากร>_<รหัสสั้น>/<ผลงาน|ประวัติการอบรม|นวัตกรรม|...>/<ปี>_<ชื่อกิจกรรม>_<รหัส>.pdf`

**การควบคุมสิทธิ์:** ไฟล์ Wichakan ถูกจำกัดตามโรงเรียนและเจ้าของพร้อม signed URL ชั่วคราว; refresh token ของ Google เก็บในตารางเฉพาะ service_role และไม่ส่งกลับ browser. การเชื่อมบัญชี Drive ต้องทำโดย Admin เท่านั้น. การเปิดเผยไฟล์บน Google Drive ต้องจัดการสิทธิ์ในบัญชี Google ด้วยตัวเอง ระบบไม่สั่งแชร์ไฟล์เป็นสาธารณะ.

**ข้อจำกัดการเชื่อมภายนอก:** หากยังไม่มี OAuth client ID/secret ระบบ Wichakan ใช้ Storage ส่วนตัวและลิงก์ Drive ที่มีอยู่ได้ตามปกติ แต่ปุ่มเชื่อม Drive จะไม่เปิดใช้งาน

## ข้อมูลย้อนหลัง 2568

ปี 2568 ถูกสร้างเป็นปีไม่ active, มีค่าเป้าหมายหลัก 27 รายการจากประกาศ SAR หน้า 150–152 และค่าเป้าหมายย่อย 57 รายการจากภาคผนวกหน้า 152–158; ไม่ได้คัดลอกข้อมูลคะแนน นักเรียน หรือหลักสูตรปี 2569 มาเป็นปี 2568

## ข้อจำกัดที่ต้องตรวจในการใช้งานจริง

- แบบประเมินรายครู 1–5 ยังต้องให้คณะกรรมการกำหนดวิธีรวมคะแนนหรือวิธีแปลงเป็นร้อยละที่อนุมัติจริงก่อนนำมาเป็นผลมาตรฐาน
- ข้อมูลเชิงคุณภาพ กิจกรรม RT/NT/O-NET และสถิติสุขภาวะต้องใช้หลักฐานจากโรงเรียน
- การแสดงผล PDF ผ่านการพิมพ์ browser อาจขึ้นอยู่กับอุปกรณ์; DOCX ส่งออกเป็นไฟล์แก้ไขได้
- การลงนามในรายงานฉบับรับรองเป็นการยืนยันสิทธิ์ Admin และบันทึกเวลาในระบบ ไม่ใช่ลายเซ็นดิจิทัลที่ออกโดยหน่วยรับรอง
