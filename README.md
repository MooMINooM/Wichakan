# Wichakan

School Academic Management System — ระบบบริหารงานวิชาการสถานศึกษา

## Status

Early development (v0.1 foundation). **Not production ready.** No real student data should be entered yet.

## Vision

A curriculum-aware system for academic years, student registry, classrooms, teacher assignments, assessment, approvals and official academic reports.

## Technology direction

- Next.js + TypeScript web application
- PostgreSQL / Supabase for relational data and authentication
- Authorization enforced server-side and by database policies
- Versioned curriculum and auditable academic records

See `docs/ROADMAP.md` and `supabase/migrations` for the first design baseline.
